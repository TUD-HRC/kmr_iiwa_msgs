# kmr_iiwa_msgs

ROS 2 message and action definitions used by [kmr_iiwa_ros2](https://github.com/TUD-HRC/kmr_iiwa_ros2).

Originally taken from https://github.com/MortenMDahl/kmriiwa_ws_devel/tree/foxy/src/kmr_msgs.

## Contents

- Messages: `KmpStatusdata`, `LbrStatusdata`
- Actions: `Gripper`, `MoveManipulator`, `ObjectSearch`, `PlanToFrame`

See the main repository at https://github.com/TUD-HRC/kmr_iiwa_ros2.
